# Bussin'

Sitio web de Bussin', producción de contenido para creadoras en Puebla y Cholula.

Stack: Next.js + TypeScript, Tailwind CSS y Framer Motion. Siguientes etapas: Supabase (reservas), Mercado Pago (anticipos) y n8n (bot de WhatsApp).

```bash
npm install
npm run dev
```

Los paquetes y ubicaciones viven en `src/data/paquetes.ts` (datos provisionales).
